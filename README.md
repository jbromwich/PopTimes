# PopTimes

Two games for mastering the times tables, sharing one progression:

- **Flash** (`flash.html`) — a quick-fire, beat-the-timer quiz
- **Conveyor** (`conveyor.html`) — an arcade game where orders roll down
  a conveyor and correct answers load the ship

`index.html` is the launcher; `shared.js` is the engine both games load
(store, mastery model, question picker, ladders, badges, sharing, and
the progress page). Design docs live in `docs/`.

Published at **https://jbromwich.github.io/PopTimes/**
